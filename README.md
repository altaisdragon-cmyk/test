Коровушкина Елизавета

Название: -- 

Для кого: для школьников и студентов  

Какая проблема: необходимость изучения математики школьниками, студентами для сдачи экзаменов и написания олимпиад 

Что делает программа: сайт или приложение для обучения темам по математике, в частности графы, теория игр, комбинаторика, вероятность, узлы и так далее. Включает в себя информационную часть, которая знакомит нас с выбранной для изучения темой, задачи для тренировки и, возможно, какой-то контроль знаний/тест 

3–5 основных функций: Меню выбора (тема --> (теория, задачи, тест (возможность выбора ответов, получение результата)). Возможность усовершенствования программы в будущем, загружая туда новые разделы (например, несвязанные с математикой или посвященные чему-то конкретному, например, ЕГЭ), темы, задачи, тесты через сайт/приложение. Возможность в будущем преподователю создавать на сайте личные уроки ученикам (создается профиль на сайте, там преподаватель создает урок, куда он добавляет темы с сайта или загружает свои. Доступ осуществляется по ссылке или через профиль преподавателя (профиль -> урок 1 -> сложение (новая строка) вычитание -> в каждом пункте теория и практика) 

Почему здесь можно использовать Go: go является языком программирования, соответственно на нем можно это создать
